Standard numeric format : هى طريقة تنسيق للارقام فابدل ما يطلع الرقم عادى بعمل عليه شويت تغيرات زى مثلا عندى 
C => Currency : دى بتخلى الرقم يكون فلوس يعنى بيضف لى الرقم العملة والعملة بتكون على حسب اعدادات الجهاز بتاعك  
F => Fixed Point : دى الى هى عدد العلامات العشرية 
N => Number : ديه بتحط فواصل 
E => Exponential : بتخلى الرقم علمى
P => Percentage : بتخلى الرقم نسبة
